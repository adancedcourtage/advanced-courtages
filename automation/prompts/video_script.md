# Format : Script vidéo courte (Darija marocaine)

Rédige **un script de vidéo courte de 30 à 45 secondes** sur le thème fourni, destiné à être lu face caméra (Reels / TikTok / Shorts).

## Langue — IMPORTANT
- Le script parlé est en **darija marocaine**, **translittérée en caractères latins** (alphabet latin + chiffres usuels 3, 7, 9 pour les sons arabes : ex. « 3andek », « 7it », « 9bel »).
- Objectif : un rendu **oral et naturel**, comme on parle vraiment, PAS de l'arabe littéraire ni du texte écrit formel.
- Les termes techniques d'assurance qui n'ont pas d'équivalent courant en darija (ex. « prévoyance », « contrat Madelin », « délai de carence ») restent en français, insérés dans la phrase en darija — c'est ainsi qu'on en parle réellement au Maroc/en France.

## Structure imposée (4 blocs, minutés)
1. **HOOK (0-5 s)** : une phrase choc en darija qui accroche direct (une question, une idée reçue, un chiffre).
2. **PROBLÈME (5-20 s)** : explique la douleur concrète du TNS, simplement.
3. **SOLUTION / INSIGHT (20-38 s)** : ce qu'il faut comprendre ou vérifier.
4. **CTA (38-45 s)** : invitation douce à faire le check-up gratuit, avec mention du lien fourni.

## Format de sortie (Markdown)
Pour chaque bloc, donne :
- Le **timing** (ex. `**[0-5 s] HOOK**`)
- La **réplique en darija** (translittérée)
- Entre parenthèses, une **courte traduction française** de la réplique, pour ta relecture.

Ajoute en toute fin une ligne `**Idée de visuel / texte à l'écran :**` avec 1-2 suggestions (ce qu'on affiche à l'écran pendant la vidéo).

## Contraintes
- Naturel, rythmé, parlé. Phrases courtes.
- Respecte les garde-fous conformité (pas de promesse garantie).
- Le CTA renvoie vers le check-up gratuit avec l'URL exacte fournie.

## Sortie
Rends UNIQUEMENT le script structuré comme demandé. Pas de commentaire autour.
